# 插件

列出所有已安裝的插件，頁面頭部的徽標會顯示當前加載的 Plugin SDK 版本(如果要對照[開發手冊](../../dev-guide/)開發插件，這個版本號很有用)。

## 每個插件的卡片

每個已安裝的插件都有一張卡片，顯示圖示、名稱、版本號、DLL 檔案名以及插件的**總體功能簡介**。

點擊卡片可以展開，查看它註冊的功能組件，按類型分組（搜尋源、動態選單提供者等）——每個可切換的組件都有自己的**啓用/禁用核取方塊**；標記為必要項的組件會顯示一個鎖形圖示，不能關閉。將滑鼠懸停在各組件上時，會彈出該組件的**詳細功能說明 ToolTip**。

當某個分組（或整個插件）有 2 個及以上可切換組件時，標題旁會出現一個**全選/全不選**鏈接，點擊即可一次性切換該範圍內的所有核取方塊，不用逐個手動勾選。

如果插件暴露了自己的配置項(超出簡單啓用/禁用的範疇)，卡片頭部會出現一個**配置**按鈕，點擊會打開該插件自己的設定對話方塊。

頁面底部有一條提示橫幅，說明部分組件的開關改動需要重啓 SwiftList 才能生效。

如果沒有安裝任何插件，頁面會顯示一個空狀態提示。

想看插件自己的**配置**對話方塊實際長什麼樣、能改什麼(比如改一個觸發關鍵詞)，可以參考[即時答案與關鍵詞功能](../instant-answers)。
