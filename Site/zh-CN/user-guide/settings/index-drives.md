# 索引

三个 Tab:**本地驱动器**、**网络驱动器**、**排除规则**。

## 本地驱动器

- 顶部状态卡片汇总已索引的驱动器数量与项目数量，并提供**重建索引**按钮做全量重扫描。
- 每个本地驱动器一行:**启用/禁用复选框**、驱动器名称、文件系统(NTFS/ReFS 等)、当前状态、已索引
  项目数，以及每行独立的**重建**/**移除**操作。
- 本地驱动器通过 Windows USN 日志持续实时更新——手动重建很少需要，但如果发现内容不同步，随时可
  以用它。

## 网络驱动器

- 与本地驱动器相同的状态卡片和**重建索引**按钮。
- 每个已映射的网络驱动器一行:启用复选框、路径/名称、状态(索引中 / 就绪 / 已缓存 / 失败 / 等待中
  / 已连接)、项目数，以及**刷新模式**下拉框:
  - **手动** —— 只在手动触发(重建索引)时刷新。
  - **每 15 分钟**
  - **每小时**
  - **每天**
- 如果检测到安装了 Windows Subsystem for Linux，会自动出现一个 **WSL 发行版** 子区域，每个发行
  版都有和网络驱动器一样的启用/状态/刷新模式控件。

网络共享没有本地 NTFS 卷那样的变更日志可供监听，所以采用定时刷新而不是实时更新。

## 排除规则

三个子 Tab，形态完全一致:一个单条输入框 + **添加**按钮，一个可编辑/删除每一条规则的列表，以及一
个批量多行文本框，配 **从列表生成** / **应用到列表** 两个按钮，用来一次性编辑全部规则。

- **路径排除** —— 完整路径或环境变量(例如 `D:\Cache`、`%ProgramData%`)。
- **Glob 通配符** —— `*`(文件名中任意字符)、`?`(单个字符)、`**`(递归目录)。示例:`*.tmp`、
  `**/node_modules/**`、`bin/**`。
- **正则表达式** —— 针对路径/文件名做部分匹配的任意正则。示例:`^\.`(隐藏文件)、`~$`(Office
  临时文件)、`\.git\`。

排除规则对本地和网络索引都生效，应用排除规则的改动后，网络驱动器会自动重新扫描。
