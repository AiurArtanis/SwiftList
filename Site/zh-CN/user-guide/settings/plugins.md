# 插件

列出所有已安装的插件，页面头部的徽标会显示当前加载的 Plugin SDK 版本(如果要对照
[开发手册](../../dev-guide/)开发插件，这个版本号很有用)。

## 每个插件的卡片

每个已安装的插件都有一张卡片，显示图标、名称、版本号和 DLL 文件名。点击卡片可以展开，查看它注册
的功能组件，按类型分组(搜索源、动态菜单提供者等)——每个可切换的组件都有自己的**启用/禁用复选
框**;标记为必要项的组件会显示一个锁形图标，不能关闭。

当某个分组(或整个插件)有 2 个及以上可切换组件时，标题旁会出现一个**全选/全不选**链接，点击即可
一次性切换该范围内的所有复选框，不用逐个手动勾选。

如果插件暴露了自己的配置项(超出简单启用/禁用的范畴)，卡片头部会出现一个**配置**按钮，点击会打
开该插件自己的设置对话框。

页面底部有一条提示横幅，说明部分组件的开关改动需要重启 SwiftList 才能生效。

如果没有安装任何插件，页面会显示一个空状态提示。

想看插件自己的**配置**对话框实际长什么样、能改什么(比如改一个触发关键词)，可以参考
[即时答案与关键词功能](../instant-answers)。
