# 关于

显示 App、Core、Service 三个组件的版本号(颜色会反映服务当前是否健康)、SwiftList 的简短说明，以
及项目主页链接。

## 检查更新

- **检查更新** 按钮 —— 查询是否有新版本;按钮文字本身会反映进度("正在检查更新..."，之后显示
  "已是最新版本"或找到的新版本号)。
- 如果非管理员账户无法停止后台服务来原地安装更新，会显示一条警告横幅，并引导你前往手动下载页
  面。
- 一旦发现新版本:
  - **静默自动更新** —— 后台下载安装，显示进度条，完成后自动重启 SwiftList。
  - **前往下载页面** —— 在浏览器中打开 GitHub release 页面，手动安装。

这个页面和[通用 → 系统](./general#系统)里的**启动时自动检查更新** / **自动静默更新**两个复选框
是配套的——那两项控制是否在启动时自动执行这次检查;这个页面则是让你随时手动触发一次。
