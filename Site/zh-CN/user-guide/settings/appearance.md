# 外观

固定在侧边栏底部、[关于](./about) 的上方。分两组:**主题模式**和主题选择器本身。

## 主题模式

- **跟随系统浅色/深色设置** —— 复选框，默认关闭。开启后 SwiftList 会在你分别指定的两个主题之
  间切换——一个用于 Windows 处于浅色模式时，一个用于深色模式时——而不是固定用一个主题，并且
  Windows 自己的设置一变化就立刻生效(不需要重启)。

## 界面主题

"跟随系统"关闭时，是一个列出所有已安装主题的卡片网格。开启后网格会拆成两组:**浅色主题**(只
列出非深色风格的主题)和**深色主题**(只列出深色风格的主题)——两者默认取符合对应风格、且恰好
排在最前面的那个已安装主题，具体有哪些主题完全取决于安装了哪些主题插件。

每个主题都以卡片形式展示，而不只是一个名字:卡片里是一个用该主题配色渲染的快速搜索窗口缩略
图(搜索框加几行搜索结果，其中一行显示为选中态)，切换前就能看到主题的实际观感。当前生效的主
题卡片上会有一个勾选徽标。

内置与随包主题插件:

- **CoreExtensions**(内置)—— 浅色、深色、北欧蓝、樱花粉、赛博朋克。
- **AnimeThemes**(随包提供，需已安装并启用)—— 新世纪、樱花盛开、天气之子。
- **臻选主题 Curated Themes**(随包提供，需已安装并启用)—— 十组浅色/深色成对主题:冰川蓝、
  陶土棕、森林绿、紫水晶、绯红、石墨灰、靛蓝夜、薄荷青、香槟金、琥珀金。

其他主题插件也可以用同样的方式往网格里再加卡片。
