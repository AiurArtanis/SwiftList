# 运行状态

管理后台索引服务，并提供其日志的实时查看。

## 服务控制

状态指示会显示**正在运行**、**已停止**或**未安装**，并配有对应的操作按钮:

- **安装并启动服务**(未安装时)
- **启动服务** / **停止服务**(已安装时)
- **卸载服务**

## 日志

三个 Tab —— **App**、**Hook**、**Service** —— 分别对应 SwiftList 运行的三个进程(你实际交互的用
户态 App、键盘钩子进程、提权的后台索引服务)。每个 Tab 显示对应进程的日志行，按等级着色。

- **等级过滤**下拉框 —— 全部 / 错误 / 警告 / 信息 / 调试。
- **搜索框** —— 按关键词过滤当前显示的行，可与等级过滤叠加使用。
- **清空日志** 按钮 —— 清空当前选中 Tab 的日志。清空 Service Tab 的日志会通过服务本身来完成(App
  进程没有权限直接改动它);App 和 Hook 的日志由于是用户态文件，可以直接清空。

排查问题时应该最先看这里——见[故障排查](../troubleshooting#还是没解决)。
