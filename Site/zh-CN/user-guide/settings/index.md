# 设置项参考

设置窗口左侧导航栏共有八个分区:

| 分区 | 内容 |
|---|---|
| [运行状态](./service-status) | 后台服务的安装/启动/停止，以及 Service/App/Hook 日志查看器。 |
| [索引](./index-drives) | 本地驱动器、网络驱动器(含 WSL 发行版)，以及排除规则。 |
| [通用](./general) | 启动行为、更新、主题、语言、搜索栏布局、预览窗口大小。 |
| [热键](./hotkeys-page) | 全局热键、各插件动作热键、进程黑名单。 |
| [收藏夹](./favorites) | 自定义命名的文件夹/文件/网址快捷方式。 |
| [历史记录](./history) | 搜索历史与快速窗口关键字历史。 |
| [插件](./plugins) | 已安装的插件及各功能组件的启用/禁用开关。 |
| [关于](./about) | 版本信息与检查更新。 |

以下每篇文章都会按顺序列出该分区的每一项设置，包括默认值和取值范围。
