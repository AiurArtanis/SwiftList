# 动作菜单与预览

## 动作菜单

每个结果——文件、文件夹或应用——除了"直接打开"之外还有一整套动作：在资源管理器中定位、复制路径、
以管理员身份运行、剪切/复制文件本身，以及插件添加的任何动作(比如完整的 Windows 右键菜单，包含级
联子菜单)。

用**打开动作菜单**热键(默认 `Ctrl+O`)或在选中结果上按方向键右键即可打开。菜单内：

- **上/下一项**——方向键，或你自己配置的[上/下一项热键](./hotkeys)，都可以移动高亮项。哪怕自定
  义绑定成了裸 `Tab` 键这种情况，在这里也会和主结果列表里表现完全一致。
- 在带子菜单的项(比如"发送到"这类级联菜单)上按**右方向键/回车**会进入子菜单；**左方向键**或
  (搜索框为空时的)**Backspace** 会退出一级。
- **Escape** 退出动作菜单；如果之前输入过内容用来过滤动作列表，会先清空搜索框。
- 输入文字可以按名称过滤当前可见的动作，和过滤搜索结果的方式一样。

## QuickLook 预览

在选中结果上按 **QuickLook** 热键(默认 `Alt+P`)会打开一个停靠在搜索窗口旁边的预览面板——图片、
文档等可预览的文件类型不用离开 SwiftList 就能查看。再按一次(或切换到 QuickLook 无法预览的结果)
即可关闭。

预览窗口的尺寸是固定的、用户可配置的——见
[设置 → 通用 → 预览窗口](./settings/general#预览)——不会随当前显示的结果数量变化。不管设置成多
大，SwiftList 都会自动保证预览窗口完整显示在屏幕内:如果配置的尺寸在当前显示器上放不下与搜索窗
口并排显示，会自动贴到有空间的一侧；如果配置的尺寸本身就比显示器可用区域还大，窗口会被缩小到能
完整放下，而不会跑到屏幕外面。

如果正在预览的文件需要它自己的原生处理程序弹出一个对话框——最常见的就是 Word 或 Excel 询问加密
文档的密码——快速窗口和预览面板会在这个弹窗存续期间自动隐藏，否则它们会挡在弹窗前面，让弹窗根本
点不到。这不是 SwiftList 崩溃或关闭了:处理完那个弹窗(输入密码、关掉它,随便什么它要求的操作)
之后，两个窗口会原样恢复，搜索内容和选中项都还在。
