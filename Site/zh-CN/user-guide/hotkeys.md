# 热键

下面所有全局与应用内热键都可以在**设置 → 热键**里重新绑定；这里列出的是默认值。设置界面本身见
[设置 → 热键页面](./settings/hotkeys-page)。

## 全局热键

| 动作 | 默认 | 说明 |
|---|---|---|
| 呼出/隐藏快速窗口 | 双击 `Ctrl` | 也可以设置成完整组合键(例如 `Alt+Space`)而不是双击模式。 |
| 快速切换 | `Ctrl+G` | 在内嵌(嵌入资源管理器)搜索栏和主窗口之间切换。 |
| 选中下一项 | `Ctrl+N` | 与方向键的下键效果相同。 |
| 选中上一项 | `Ctrl+P` | 与方向键的上键效果相同。 |
| 跳转到结果 1–9 | `Ctrl` + 数字 | 修饰键可自定义;数字固定为 1–9。 |
| 打开动作菜单 | `Ctrl+O` | 与在选中结果上按方向键右键效果相同。 |
| 从选中项补全 | `Ctrl+Tab` | 在快速窗口里，用选中结果的名称/路径填充搜索框。 |
| QuickLook 预览 | `Alt+P` | 切换选中结果的预览面板。 |
| 上一条关键字历史 | `Alt+Up` | 向前翻阅最近输入过的搜索词。 |
| 下一条关键字历史 | `Alt+Down` | 向后翻阅最近输入过的搜索词。 |
| 删除当前关键字历史 | `Shift+Delete` | |
| 初始面板下一个标签 | `Ctrl+Right` | 到最后一个标签后会循环回第一个。只有[初始面板](./settings/startup-panel)正在显示时才生效——否则这个按键正常做它原本的事(比如在输入查询词时移动光标)。 |
| 初始面板上一个标签 | `Ctrl+Left` | 到第一个标签后会循环回最后一个。同样只有面板显示时才生效。 |

## 快速导航(鼠标)

默认启用，每种触发方式都可单独在设置里开关：

- 在桌面或资源管理器窗口的空白处**双击左键**触发快速导航。
- 在桌面或资源管理器窗口的空白处、受支持的第三方文件管理器(Directory Opus、Total Commander 等)的
  文件列表区域、或原生的打开/保存/浏览文件夹对话框里**点击中键**触发快速导航。这些其它窗口只响应
  中键——双击在那里已经是"打开这一项"的意思，所以没有把双击挪作他用。

无论哪种方式触发，都会弹出一个级联菜单，内容是你的收藏夹、历史记录和配置好的快捷文件夹(见
[设置 → 收藏夹](./settings/favorites)和[设置 → 历史记录](./settings/history))——插件也可以往里加
自己的条目，比如你在 `wincmd.ini` 里配置过 Total Commander 的 Directory Hotlist 的话，它也会出现在
这里。点击文件夹会让目标窗口跳转过去；点击文件会打开它。如果是在文件选择器里，点击文件则是让对话
框跳转到该文件所在的文件夹——绝不会替你自动确认"打开"/"保存"。

## 硬编码按键(不可配置)

无论热键设置如何，以下按键始终保持相同行为：

| 按键 | 场景 | 行为 |
|---|---|---|
| `Escape` | 任意场景 | 若搜索框有内容则清空;否则关闭窗口(或退出动作菜单)。 |
| `Enter` | 结果列表 | 打开选中结果。 |
| `Ctrl+Enter` | 结果列表 | 在资源管理器中定位该结果，而不是打开它。 |
| `Ctrl+Shift+Enter` | 结果列表 | 以管理员身份打开该结果。 |
| 左/右方向键 | 动作菜单 | 返回上一级菜单 / 进入子菜单。 |
| `Backspace` | 动作菜单 | 当搜索框已为空时，退出动作菜单。 |

## 插件动作热键

插件可以注册自己的动作并附带一个默认热键(例如复制路径、以管理员身份运行)。这些会显示在
**设置 → 热键 → 插件动作** 里，按注册它们的插件分组，重新绑定方式和内置热键相同。

## 进程黑名单

如果 SwiftList 的全局热键和某个应用(比如会独占键盘原始输入的游戏)冲突，把该进程加入**进程黑名
单**即可——详见[设置 → 热键页面](./settings/hotkeys-page#process-blacklist)。当黑名单里的进程处
于前台时，SwiftList 的全局热键会被完全放行，不会拦截。
