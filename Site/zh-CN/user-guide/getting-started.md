# 快速上手

## 安装

在首页的[下载按钮](../)获取最新版本——每次发布都会提供两种形式：

- **安装包**(`SwiftList-Setup.exe`)—— 推荐使用。会注册后台索引服务，也可以设置为随 Windows
  启动。
- **便携版**(`SwiftList-Portable.zip`)—— 解压即可运行，无需安装。之后仍然可以在
  **设置 → 运行状态** 里手动安装后台服务。如果电脑上还没有 SwiftList 需要的 .NET 桌面运行时，运行
  一次自带的 `install-dotnet-runtime.bat` 即可——安装包会自动处理这一步，但便携版做不到。

首次运行时，SwiftList 会安装并启动一个 Windows 服务(`SwiftList.Service`)，专门负责文件索引。这
个拆分是有意为之的——如果好奇原因可以参考[架构设计](../dev-guide/architecture)——但作为普通
用户，只需要知道：**设置 → 运行状态** 页面会告诉你服务是否已安装、是否在运行，如果还没安装，也
可以在这里安装。

## 三种窗口

SwiftList 不是只有一个搜索窗口——它会根据使用场景自动适配：

- **主窗口** —— 从任务栏/开始菜单快捷方式打开的完整窗口，结果列表最大，还带有窗内动作面板。
- **快速窗口** —— 按下全局呼出热键(默认双击 `Ctrl`)召唤出来的紧凑型置顶弹窗，专为"按热键 → 输
  入 → 回车"这套肌肉记忆设计。
- **内嵌窗口** —— 直接把 SwiftList 的搜索框嵌入到受支持的原生文件对话框或文件资源管理器窗口里，
  不用离开当前对话框就能搜索。

三种窗口共用同一套搜索引擎、热键系统和动作菜单——区别只在于它们出现的位置和形态。

## 基本搜索

清空搜索框(或者重新打开快速窗口)时，看到的不是空的结果列表，而是[初始面板](./settings/startup-panel)
——一个标签栏，不用输入查询就能快速访问最近文件、收藏夹和历史记录。

直接开始打字即可。结果会随输入实时更新，并按相关度排序(匹配与排序的原理见
[搜索语法](./search-syntax))。用[可配置的上/下一项热键](./hotkeys)(默认是方向键)移动选中项，
回车打开高亮的结果。
