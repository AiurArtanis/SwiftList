# 外掛

列出所有已安裝的外掛，頁面頂部的徽章會顯示目前載入的 Plugin SDK 版本(如果要對照
[開發手冊](../../dev-guide/)開發外掛，這個版本號很有用)。

## 每個外掛的卡片

每個已安裝的外掛都有一張卡片，顯示圖示、名稱、版本號、DLL 檔案名稱以及外掛的**整體功能簡介**。

點擊卡片可以展開，檢視它註冊的功能元件，按類型分組（搜尋來源、動態選單提供者等）——每個可切換的元件都有自己的**啟用/停用核取方塊**；標記為必要項目的元件會顯示一個鎖形圖示，不能關閉。將滑鼠停留在各元件上時，會彈出該元件的**詳細功能說明 ToolTip**。

當某個分組（或整個外掛）有 2 個及以上可切換元件時，標題旁會出現一個**全選/全不選**連結，點擊即可一次性切換該範圍內的所有核取方塊，不用逐個手動勾選。

如果外掛公開了自己的設定項(超出簡單啟用/停用的範疇)，卡片頂部會出現一個**設定**按鈕，點擊會開
啟該外掛自己的設定對話方塊。

頁面底部有一條提示橫幅，說明部分元件的開關改動需要重新啟動 SwiftList 才能生效。

如果沒有安裝任何外掛，頁面會顯示一個空狀態提示。

想看外掛自己的**設定**對話方塊實際長什麼樣、能改什麼(比如改一個觸發關鍵字)，可以參考
[即時答案與關鍵字功能](../instant-answers)。
