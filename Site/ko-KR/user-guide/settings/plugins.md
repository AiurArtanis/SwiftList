# 플러그인

설치된 모든 플러그인을 나열하며, 페이지 헤더에 현재 로드된 Plugin SDK 버전이 배지로 표시됩니다
([개발자 매뉴얼](../../dev-guide/)과 플러그인을 맞춰볼 때 유용합니다).

## 플러그인별 카드

설치된 각 플러그인은 아이콘, 이름, 버전, DLL 파일명, **전체 기능 설명**을 보여주는 카드를 얻습니다.

카드를 클릭하면 펼쳐지면서 등록된 컴포넌트가 유형별(검색 제공자, 동적 메뉴 제공자 등)로 그룹화되어
나타납니다 — 전환 가능한 각 컴포넌트는 자체 **활성화/비활성화 체크박스**를 가지며, 필수로 표시된
컴포넌트는 대신 자물쇠 아이콘을 보여주고 끌 수 없습니다. 컴포넌트에 마우스를 올리면 **상세 기능
툴팁**이 나타납니다.

그룹(또는 플러그인 전체)에 전환 가능한 컴포넌트가 둘 이상 있으면, 헤더 옆에 **모두 선택 / 모두 선택
해제** 링크가 나타나 한 번에 하나씩이 아니라 그 범위의 모든 체크박스를 한꺼번에 뒤집을 수 있습니다.

플러그인이 자체 설정(단순한 활성화/비활성화를 넘어선 커스텀 설정)을 노출한다면, 카드 헤더에 **구성**
버튼이 나타나 해당 플러그인 자체의 설정 대화상자를 엽니다.

페이지 하단의 배너는 일부 컴포넌트 토글이 SwiftList를 재시작한 후에만 적용된다는 점을 상기시켜 줍니다.

설치된 플러그인이 없다면, 페이지는 대신 빈 상태 메시지를 보여줍니다.

플러그인 자체의 **구성** 대화상자가 실제로 어떤 모습인지에 대한 구체적인 예시(예: 트리거 키워드
변경)는 [즉시 답변 및 키워드 단축 명령](../instant-answers)을 참고하세요.
