# プラグイン

インストール済みのすべてのプラグインを一覧表示し、現在読み込まれているプラグイン SDK のバージョンをページヘッダーにバッジとして表示します([開発者ガイド](../../dev-guide/)と照らし合わせてプラグインを開発している場合に役立ちます)。

## プラグインごとのカード

インストールされたプラグインごとに、アイコン、名前、バージョン、DLL ファイル名、**全体的な機能の説明** を示すカードが表示されます。

カードをクリックすると展開し、種類(検索プロバイダー、動的メニュープロバイダーなど)ごとにグループ化された登録済みコンポーネントが表示されます。切り替え可能な各コンポーネントには専用の **有効/無効チェックボックス** があります。必須とマークされたコンポーネントは代わりに鍵アイコンが表示され、オフにできません。コンポーネントにカーソルを合わせると **詳細な機能のツールチップ** が表示されます。

グループ(またはプラグイン全体)に切り替え可能なコンポーネントが2つ以上ある場合、そのヘッダーの横に **すべて選択/すべて選択解除** リンクが表示され、そのスコープ内のすべてのチェックボックスを1つずつではなく一括で切り替えられます。

プラグインが独自の設定(単純な有効/無効を超えたカスタム設定)を公開している場合、カードのヘッダーに **設定** ボタンが表示され、そのプラグイン独自の設定ダイアログが開きます。

ページ下部のバナーは、一部のコンポーネントの切り替えが SwiftList の再起動後にのみ反映されることを知らせます。

プラグインが1つもインストールされていない場合、代わりに空の状態メッセージが表示されます。

プラグイン独自の **設定** ダイアログが実際にどのようなものかの具体例(トリガーキーワードの変更など)については、[インスタントアンサーとキーワードショートカット](../instant-answers)を参照してください。
